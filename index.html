⚙️ Setup Guide
1. Google Cloud Console
Go to console.cloud.google.com → New Project → Enable Google Sheets API
2. OAuth Consent Screen
APIs & Services → OAuth consent screen → External → Add team Gmail accounts under Test users
3. OAuth Client ID
Credentials → Create → Web application → Authorized JS origins: https://username.github.io
4. Google Sheet
Create a new Sheet → Add 3 tabs: Clients, History, Sales Team → Copy the Sheet ID from the URL
5. Edit index.html
Find YOUR_CLIENT_ID_HERE and YOUR_SHEET_ID_HERE and replace with real values → Click "Initialize Sheets" to create headers
📦 Archive & Reset

Select the month to archive. All current client statuses will be saved to History, then reset to Grey for the new month.

This will be the label used in the History tab.
