ทำตามขั้นตอนด้านล่างเพื่อเชื่อมต่อ Google OAuth และ Google Sheets

ขั้นที่ 1 — สร้าง Google Cloud Project
ไปที่ console.cloud.google.com → สร้าง Project ใหม่ → Enable APIs: Google Sheets API และ OAuth 2.0
ขั้นที่ 2 — ตั้งค่า OAuth Consent Screen
APIs & Services → OAuth consent screen → เลือก External → กรอกชื่อ App → ในส่วน Test users ให้ใส่ Gmail ของทีมทุกคน
ขั้นที่ 3 — สร้าง OAuth Client ID
APIs & Services → Credentials → Create Credentials → OAuth client ID → ประเภท Web application → Authorized JavaScript origins: https://ชื่อของคุณ.github.io
ขั้นที่ 4 — สร้าง Google Sheet
สร้าง Google Sheet ใหม่ → เพิ่ม 4 ชีต: ลูกค้า, กิจกรรม, คำสั่งซื้อ, การแจ้งเตือน → Share กับทุกคนในทีม (Editor) → คัดลอก Sheet ID จาก URL (ส่วนที่อยู่ระหว่าง /d/ และ /edit)
ขั้นที่ 5 — แก้ไขไฟล์ index.html
ค้นหา YOUR_CLIENT_ID_HERE และ YOUR_SHEET_ID_HERE แล้วแทนที่ด้วยค่าของคุณ
ขั้นที่ 6 — Deploy บน GitHub Pages
สร้าง GitHub repository (public) → อัปโหลด index.html → Settings → Pages → Source: main branch → บันทึก → รอ ~1 นาที แล้วเข้า URL ที่ได้
